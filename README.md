# Отиёт (Otiyot) — Карточки Молитв и Благословений

Мобильное веб-приложение (PWA) с двусторонними интерактивными карточками для изучения традиционных еврейских молитв, благословений и базовых текстов на иврите.

## 📱 Онлайн-версия (GitHub Pages)

Приложение доступно онлайн:
👉 **[https://sofyapl.github.io/otiyot/](https://sofyapl.github.io/otiyot/)**

### Как установить на телефон (PWA):
* **Android (Chrome):** В меню (три точки) выберите **«Установить приложение»** — приложение появится на рабочем столе с собственной иконкой и будет работать как отдельная программа.
* **iPhone (Safari):** Нажмите кнопку **«Поделиться»** $\rightarrow$ выберите **«На экран „Домой“»**.

Приложение открывается без адресной строки браузера и работает автономно (офлайн).

## ✨ Возможности приложения

* **Двусторонние карточки:** Лицевая сторона — крупный текст на иврите с огласовками (некудот); оборотная сторона — русская транскрипция, точный перевод и практические комментарии.
* **Интерактивность:** 3D-переворот карточек по клику/пробелу, плавные свайпы влево/вправо на телефоне, стрелки навигации.
* **Сортировка и кастомизация:** Возможность менять порядок карточек, ставить актуальную молитву на первое место для быстрого доступа при старте.
* **Фильтрация по категориям:** Быстрый переход между категориями (Утренние, Благословения, Еда и др.).
* **Озвучка:** Встроенный синтез речи для прослушивания правильного произношения на иврите.
* **Редактирование и добавление:** Создание карточек прямо в интерфейсе, удобный выбор категорий в 1 клик, а также быстрая массовая загрузка из таблиц (Excel / Google Таблицы) со ссылками на аудио и массовым прикреплением MP3-файлов.
* **Автономность и приватность:** Все данные хранятся локально в памяти устройства (LocalStorage). Поддерживается резервное копирование и восстановление через JSON.
* **Умная синхронизация:** Возможность обновлять официальную базу карточек из общего каталога без потери персональных правок.

## 🚀 Локальный запуск на компьютере

### Способ 1 (В 1 клик на Windows):
Запустите файл **`ЗАПУСК_ПРИЛОЖЕНИЯ.bat`** в папке проекта.

### Способ 2 (Через терминал):
```bash
cd app
npm start
```
Сервер запустится на `http://localhost:3000` и покажет адрес для доступа с мобильных устройств в локальной сети.
